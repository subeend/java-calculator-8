# java-calculator-precourse

# 문자열 덧셈 계산기 


## 기능 목록

###  사용자 입력

* `Console.readLine()`으로 문자열을 입력받는다.
* **빈 문자열 또는 공백만** 입력된 경우 → **결과 0 반환**(예외 아님)

###  문자열 형식 유효성 검사

* 허용 구분자: 기본 구분자 `,` `:` 또는 커스텀 구분자(형식: `"//<문자>\n"`).
* 커스텀 구분자가 있으면 **기본 구분자와 함께** 인식한다.
* 형식이 올바르지 않거나 토큰이 비어 있으면 → `IllegalArgumentException`
  

###  숫자 추출

* (기본/커스텀) 구분자를 기준으로 숫자 토큰을 분리한다.
* 각 토큰은 `trim()` 후 **순수 숫자**여야 한다.
  숫자가 아니면 → `IllegalArgumentException`

###  유효 값 검사

* **양수만 허용**한다.
  `0`, 음수, 범위를 벗어난 값 등은 → `IllegalArgumentException`

###  합산 및 출력

* 모든 유효 숫자를 더해 결과를 계산한다.
* 출력 포맷: `결과 : <합계>`
